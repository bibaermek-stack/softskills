## 2. Технологиялық стек және іске қосу

### Стек

| Қабат | Технология |
|---|---|
| Фреймворк | **Next.js 15.5** (App Router), React 19, TypeScript 5 |
| Стиль | Tailwind CSS v4 (`@tailwindcss/postcss`) |
| Күй (state) | Zustand 5 |
| 3D | React Three Fiber 9 + drei 10 + three.js 0.185 |
| Анимация | Framer Motion 12, GSAP 3 (ScrollTrigger), Lenis (smooth scroll) |
| Backend | Supabase (Postgres + Auth + Realtime), `@supabase/ssr` |
| Формула | KaTeX 0.18 |
| QR | `qrcode` |
| Иконка | `lucide-react` |
| AI | OpenRouter API (DeepSeek V4 Flash) |
| 3D пайплайн | `@gltf-transform/*`, `meshoptimizer`, `sharp` |

### Іске қосу

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # өнімдік құрастыру
npm run lint     # ESLint
npm run optimize:models -- <GLB-файлдар каталогы>
```

### Орта айнымалылары (`.env.local`)

```
NEXT_PUBLIC_SUPABASE_URL=https://<project>.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...   # немесе NEXT_PUBLIC_SUPABASE_ANON_KEY
OPENROUTER_API_KEY=sk-or-...                              # AI ассистенті үшін
OPENROUTER_MODEL=deepseek/deepseek-v4-flash               # міндетті емес
```

> **Маңызды.** Supabase кілттері берілмесе, платформа **демонстрациялық режимде** жұмыс істейді: тіркелгі мен оқу нәтижелері браузердің `localStorage`-ында сақталады. Кілт өзгертілген соң dev серверді қайта іске қосу керек — Next.js `NEXT_PUBLIC_*` айнымалыларын старт кезінде оқиды.

### `next.config.ts` шешімдері

- `outputFileTracingRoot: __dirname` — бөгде lockfile-дың workspace түбірін бұрыс табуын болдырмайды.
- `transpilePackages: ["three"]` — three кейбір жерде транспиляцияланбаған ESM күйінде жеткізіледі.
- `optimizePackageImports: ["framer-motion", "@react-three/drei"]`.
- `/models/:path*` үшін `Cache-Control: public, max-age=31536000, immutable` — модельдер атауымен хештелген, орнында өзгермейді.

## 4. Ақпараттық бөлім — көпшілік сайт

Басты бет 14 бөлімнен тұрады (`app/(site)/page.tsx`). Барлық мәтін — **`lib/content.ts`** ішінде, ол мазмұнның жалғыз дереккөзі. Түсініктемелердегі § нөмірлері жобаның ғылыми сипаттамасының бөлімдеріне сілтейді.

### 4.1 Hero — басты экран

![Басты экран](screenshots/01-home.png)

Экранның жалғыз WebGL контексті осында: жарқыраған платформада **төрт нақты GLB кітап** тұрады. Олар айналады, тербеледі, меңзерге қарай еңкейеді, үстіне апарғанда жарқырап бөлшек шығарады, ал басқанда камера жақындап, сол томның мазмұны бар оқу панелі ашылады.

Көрсеткіштер: 5 кіріктірілген пән · 16 инновациялық технология · 10 командалық рөл · 8 бағалау түрі.

Төрт кітап — жобаның нақты қазақша STEM оқулықтары:
1. Физиканы оқыту әдістемесі
2. Механика курсындағы STEM элементтер
3. Физикалық эксперименттерді VR технологиясы арқылы ұйымдастыру негіздері
4. Физика пәні мұғаліміне 3D модельдеу мен VR технологиясының маңызы

### 4.2 About — платформа туралы (§1–2)

Миссия, көрініс және **жеті кезеңді хронология**: зерттеу негізі → STEM білімнің маңызы → креативті тәрбие → пәнаралық оқыту → нақты өмірлік мәселені шешу → бейімделген білім беру → икемді дағдыларды дамыту.

Мұнда бейімделген модельдің **тоғыз кезеңі** және **он оқыту әдісі** де беріледі:

*Тоғыз кезең:* мәселені анықтау → пәнаралық талдау → зерттеу сұрағы → дерек жинау → модель құру → шығармашылық шешім → прототип → таныстыру → рефлексия.

*Он әдіс:* жобалық, проблемалық, зерттеуге негізделген оқыту, рөлдік/іскерлік ойындар, пікірталас, кейс-стади, дизайн-ойлау, командалық тапсырмалар, цифрлық модельдеу, өзара оқыту.

## 6. Аутентификация және рөлдер

![Кіру терезесі](screenshots/29-auth-modal.png)

### Рөлдер

`student` · `teacher` · `admin` (`UserRole`).

### Кіру жолдары

1. **Email + құпия сөз** — тіркелу формасында рөл таңдалады.
2. **Google OAuth** — рөл `/auth/callback?role=…` арқылы қайтады немесе callback бетінде «Сіз кімсіз?» экраны бір рет сұрайды.
3. **Демонстрациялық жылдам кіру** — тіркелусіз: 🎓 Студент (Айгерім Болатқызы) немесе 👨‍🏫 Оқытушы (Серік Полатұлы).

### Рөлді қорғау

- Рөл `auth.users.raw_user_meta_data`-ға жазылады, `handle_new_user()` триггері `profiles`-ке көшіреді.
- `protect_profile_identity()` рөл мен кодты кейін өзгертуге жол бермейді.
- `roleLocked = false` тек OAuth тіркелуі мен рөл таңдау арасында ғана болады; `claim_role()` екінші шақыруда қате береді.

### Пайдаланушы коды

Әркімге тіркелген сәтте өзгермейтін қысқа код беріледі: `STU-A7K2M9` / `TCH-PJC3YS`. Ол navbar-да көрінеді, бір басқанда көшіріледі және іздеуде қолданылады.

### Оқытушы ↔ студент байланысы

- `teacher_links` — иерархиялық байланыс (pending / accepted / declined).
- Сұранысты **тек екінші жақ** қабылдай алады — бұл дерекқор триггерінде де бекітілген.
- `friend_links` — студент ↔ студент достығы, симметриялы, жұп реттелмеген түрде бірегей.
- `search_people()` — код, аты-жөні немесе **толық** email арқылы іздеу (email нәтижеде қайтарылмайды).

### 12.3 XP жүйесі

**Ереже:** XP жинақталып емес, **есептеліп** шығады — жазбалардан қайта саналады, сондықтан қайталап шақырса да сан өзгермейді.

`compute_xp()` (миграция 0009) және оның клиенттік айнасы `lib/xp.ts`:

| Дереккөз | Формула | Ерекшелігі |
|---|---|---|
| Тест | `round(100 × score / total)` | Сабақ бойынша **ең жақсысы** |
| Ойын | `round(score × 0.5)` | (сабақ, ойын түрі) бойынша ең жақсысы |
| БӨЖ | `round(grade × 0.8)` | Тек `reviewed` мәртебесінде |
| Рубрика | `round(percent × 0.4)` | Сабақ бойынша ең жақсысы |
| Дуэль | жеңіс +30, тең +10, жеңіліс 0 | |

Триггерлер XP-ді әр жазудан кейін жаңартады — соның ішінде **мұғалім баға қойғанда да** (ол басқа адамның жазуы, клиент оны байқамай қалар еді).

### 12.4 Жергілікті прогресс (`lib/progress.ts`)

**Кілт:** `vstem-progress-v1` (localStorage), ең көбі **200 жазба**.

`ProgressRecord` төрт әрекет түрін тіркейді: `quiz` · `game` · `sim` · `case`.

Жазбада: сабақ ID, пән, кезең, ұпай (0–100 немесе `null`), дұрыс/барлығы, әрекет саны, ұзақтық (мс), ойын түрі, **дағдылар** және сұрақ деңгейіндегі жауаптар.

**Маңызды инженерлік ереже:** мұндағы ешбір функция **рендер кезінде** шақырылмайды — `localStorage` серверде жоқ, оны рендерде оқу гидратация сәйкессіздігіне әкеледі. Оқу тек `useEffect` ішінде жүреді.

**Қателерге төзімділік:** бүлінген жазба болса, сол жазба ғана алынып тасталады; орын бітсе, соңғы 50 жазбамен бір рет қайталап көреді.

**Есептелетін көрсеткіштер:**
- `weeklyActivity()` — соңғы 7 күндегі белсенділік
- `skillProfile()` — 8 осьтік дағды радары (кейс өз дағдыларын жазбаның өзіне жазады, сондықтан радарға жетеді)
- `summary()` — жазба саны, орташа ұпай, минут
- `lessonStatus()` — `none` / `started` / **`done`** (ойын да, тест те орындалғанда)

1. Барлық жауап **таза, сауатты қазақ тілінде**, жылы әрі жігерлендіретін ғылыми-педагогикалық үнмен.
2. Физика, математика, химия, биология, бағдарламалау (Python, JavaScript, робототехника) және икемді дағдылар бойынша терең әрі түсінікті түсіндіру.
3. Формулалар **міндетті түрде LaTeX синтаксисімен**: блоктық `\[ E = mc^2 \]` / `$$…$$`, мәтін ішінде `\( F = ma \)` / `$…$`. Оларды `KatexFormula.tsx` рендерлейді.
4. Маңызды түсініктер қара қаріппен, тармақталған тізіммен және мысалдармен.
5. Қажет болса қысқаша мысал есеп немесе өмірден практикалық мысал.

### Педагогикалық принцип

Ассистент тапсырманы түсіндіреді, бағыттаушы сұрақ қояды және жоба кезеңдерін жоспарлауға көмектеседі — **бірақ ешқашан дайын жауап бермейді**. Мақсаты — өздігінен шешім табуға ынталандыру.

## 16. 3D графика және модельдерді оңтайландыру

### Оңтайландыру нәтижесі

| | Бастапқы (Meshy экспорты) | Репозиторийдегі |
|---|---|---|
| Бір кітап | ~56 МБ | **~0.28 МБ** |
| Төрт кітап | 226 МБ | **1.14 МБ** |
| Үшбұрыш | ~2 млн | **39.5 мың** |
| Текстура | 2048px JPEG | 1024px WebP × 3 |

**99.5% қысқарту.**

### Пайплайн

```bash
npm run optimize:models -- <бастапқы-GLB-каталогы>
```

`dedup → resample → weld → simplify (2%) → texture resize 1024 + WebP → prune → meshopt quantisation`

### Екі әдейі жасалған таңдау

1. **Meshopt, Draco емес.** drei-дің `useGLTF` meshopt декодерін three-stdlib арқылы бірге жеткізеді, ал оның Draco жолы Google CDN-нен декодерді орындалу кезінде жүктейді. Сондықтан `Book.tsx` `useGLTF(url, false, true)` шақырады.
2. **HTML белгілер, drei `<Text>` емес.** troika-three-text әдепкі қаріпін `fonts.gstatic.com`-нан алады. Үстіне апарғандағы тақырыптар drei `<Html>` арқылы рендерленеді — сайттың өз қаріпінде, таңдалатын және қолжетімді.

### WebGL контексті

Hero — беттің **жалғыз** WebGL контексті. `#books` бөлімі сол төрт томды қарапайым DOM ретінде көрсетіп, Hero сахнасын `lib/bookBus.ts` арқылы басқарады.

## 17. Қолжетімділік, тіл және типографика

### Тіл

Сайттың негізгі тілі — **қазақша** (`<html lang="kk">`). Барлық мәтін `lib/content.ts`, `lib/dashboard.ts` және `data/` ішінде.

### Қаріптер

| Қаріп | Қолданылуы |
|---|---|
| **Manrope** | Тақырыптар (display) |
| **Inter** | Негізгі мәтін |

Қаріптер кирилл әліпбиін, оның ішінде **`cyrillic-ext`** ішкі жиынын қолдауы міндетті — қазақтың **ә, ғ, қ, ң, ө, ұ, ү, һ** әріптері сонда орналасқан.

> Бастапқы нұсқада қолданылған **Sora** қаріпінде кирилл әліпбиі мүлдем жоқ (тек `latin` / `latin-ext`), сондықтан ол ауыстырылды. Қаріпті ауыстырғанда `cyrillic` және `cyrillic-ext` ішкі жиындарының бар-жоғын міндетті түрде тексеріңіз.

### Қолжетімділік

- **`prefers-reduced-motion`** толық құрметтеледі: Lenis инициализацияланбайды, скролл ашылымдары статикалық рендерленеді, 3D айналу/тербелу/бөлшектер тоқтайды.
- WebGL canvas-та фокус алатын нысан жоқ, сондықтан Hero әр кітапқа **нақты түйме** де рендерлейді — фокус түскенше көрінбейді.
- Skip link, `focus-visible` сақиналары, белгіленген форма өрістері, демо формасында `aria-live` күйі.
- Галерея лайтбоксы пернетақтадан толық басқарылады: `Esc` / `←` / `→`.
- Сабақ кезеңдерінде `aria-current="step"`, модуль прожекторында `aria-pressed`.
- Диаграммаларда «Кесте ретінде қарау» — сол сандар мәтін түрінде.
- 375 px-те де, десктопта да көлденең асып кету жоқ.
